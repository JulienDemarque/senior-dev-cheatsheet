# Senior dev cheatsheet

Definitions of technical terms with enough context for senior-level discussions: tradeoffs, pitfalls, and **small implementation examples** (Python, SQL, HTTP, Redis, K8s, etc.). Each topic lives in its own Markdown file; use your editor search or the index below.

Repo meta: [Contributing](./CONTRIBUTING.md) · [MIT License](./LICENSE)

## How to use

- Browse by domain using the file list.
- Search globally for a term (most headings match the term name).
- Terms that mean different things in different contexts (e.g. **Queue**) are disambiguated in the relevant file.
- Examples are illustrative—verify against current library and vendor docs before production use.
